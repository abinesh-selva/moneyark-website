# Zentally Dynamic Website (React)

A high-fidelity, neo-minimalist marketing website for Zentally, reimagined as a **Single Page Application (SPA)** using React and Vite.

## 🚀 Features
- **Dynamic Routing**: Instant page transitions via `react-router-dom`.
- **Component-Based**: Modular `Header`, `Footer`, and `BottomNav` components.
- **Stateful UI**: Active link tracking and coordinated animations.
- **Premium Aesthetics**: Mesh gradients, noise overlays, and floating glassmorphism.

## 🛠️ Stack
- **Framework**: React 18
- **Build Tool**: Vite 5 (Node 18 compatible)
- **Styling**: Tailwind CSS 3.4
- **Routing**: React Router 6

## 📂 Architecture
- `src/App.jsx`: Main routing logic and global layout.
- `src/components/`: Reusable UI components.
- `src/pages/`: Page-level components (Home, Pricing, Privacy).
- `src/style.css`: Unified design system tokens.

## 🏁 Getting Started

```bash
cd website
npm install
npm run dev
```

## 🏗️ Production Build
```bash
npm run build
```
